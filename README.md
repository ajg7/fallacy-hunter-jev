# fallacy-hunter-jev

Fallacy Hunter: a Jev project

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · shadcn/ui · TanStack Router (file-based) · TanStack Query · Zustand · Axios

Tooling: ESLint · Prettier · Vitest + React Testing Library · Playwright

## Scripts

| Command                | What it does                                 |
| ---------------------- | -------------------------------------------- |
| `npm run dev`          | Start the dev server                         |
| `npm run build`        | Type-check and build for production          |
| `npm run lint`         | ESLint                                       |
| `npm run format`       | Format with Prettier                         |
| `npm run format:check` | Check formatting                             |
| `npm run test`         | Vitest in watch mode                         |
| `npm run test:run`     | Vitest once                                  |
| `npm run test:e2e`     | Playwright e2e (builds and serves the app)   |
| `npm run check`        | Typecheck + lint + format check + unit tests |

First-time Playwright setup: `npx playwright install chromium`.

## Backend (`server/`)

A NestJS API with the [TypeSafe](https://docs.typesafe.ai) SDK (`@typesafe-ai/sdk`, model Jev)
installed. It has its own `package.json`: run `npm --prefix server install` once.

1. Copy `server/.env.example` to `server/.env` and set `TYPESAFE_API_KEY`. The key stays on the server.
2. `npm run dev:server` starts it on port 3000, with routes under `/api`.
3. `npm run dev` proxies `/api` to it, so the frontend calls `/api/...` directly.

| Command                | What it does                                       |
| ---------------------- | -------------------------------------------------- |
| `npm run dev:server`   | Start the API in watch mode                        |
| `npm run check:server` | Typecheck + lint + format check + unit & e2e tests |

## Code style

- Double quotes everywhere (enforced by Prettier).
- No nested or redundant ternaries (`no-nested-ternary`, `no-unneeded-ternary`).
- Routes live in `src/routes/`; `src/routeTree.gen.ts` is generated by the router plugin.
- `@/` aliases `src/`. Add shadcn components with `npx shadcn@latest add <name>`.
- HTTP calls go through `src/lib/api-client.ts` (Axios, base URL from `VITE_API_URL`).
